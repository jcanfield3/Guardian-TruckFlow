# TruckFlow Beta

**Owner Operator Load Profitability Platform**
Built by Guardian Holdings LLC — St. Paul, Minnesota

---

## What This Is

TruckFlow is a load profitability calculator built by a 30-year CDL-A veteran for owner-operators who want to know if a load makes money before their wheels turn.

This is the public beta version — no login required. Owner-operators enter their name and equipment type, then use Quick Check to evaluate any load for profitability.

## Equipment Supported

- **Flatbed / Step Deck** — Rate per mile scoring (TAKE ≥$2.00/mi · REVIEW ≥$1.40/mi)
- **Dump Truck** — All four types (Standard, End, Side, Belly) with Per Ton, Per Hour, and Flat Rate pricing
- **Container / Drayage** — 8-zone pay table (0-200 miles from railyard) with full accessorial tracking

## Features

- Quick Check profitability calculator — all three equipment categories
- Shared Broker Memory — community-rated broker database
- Feedback system — operator suggestions shape the next version
